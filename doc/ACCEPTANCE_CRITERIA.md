# 验收标准（Acceptance Criteria）

> 项目：SRun（Super Run — 更好地运行）
> 用途：作为开发完成、提测、发布的统一验收依据
> 覆盖范围：功能、性能、跨平台、用户体验、安全隐私

---

## 一、功能验收

### 1.1 硬件检测

| # | 验收项 | 通过条件 | 优先级 |
|---|--------|---------|--------|
| F-01 | CPU 检测 | 正确获取并展示：型号名称、厂商、物理核心数、逻辑线程数、基础频率、最大睿频、架构 | P0 |
| F-02 | GPU 检测 | 正确获取并展示：型号名称、厂商、显存大小、驱动版本；能区分独立显卡与集成显卡 | P0 |
| F-03 | 内存检测 | 正确获取并展示：总物理内存、当前可用内存、内存类型（DDR4/DDR5/LPDDR5）、频率 | P0 |
| F-04 | 磁盘检测 | 正确获取并展示：磁盘类型（HDD/SSD/NVMe）、总容量、剩余空间 | P0 |
| F-05 | 操作系统检测 | 正确获取并展示：平台（Windows/macOS/Linux）、版本号、架构（x86_64/aarch64） | P0 |
| F-06 | 检测进度反馈 | 扫描过程中实时显示进度（百分比或阶段描述），不允许界面无响应超过 500ms | P1 |
| F-07 | 检测失败容错 | 某项检测失败时不中断整体流程，该项错误标记为"未知"，其余项正常展示 | P1 |
| F-08 | 自定义硬件要求 | 允许用户通过指定的格式导入自定义配置| P1 |

### 1.2 游戏兼容性评估

| # | 验收项 | 通过条件 | 优先级 |
|---|--------|---------|--------|
| F-08 | 内置游戏库(游戏的配置要求) | 预置 ≥ 100 款主流游戏（含 Steam 热门榜 + 近 3 年 3A 大作） | P0 |
| F-09 | 游戏搜索 | 支持按名称模糊搜索，输入 2 个字符即开始匹配，响应 < 200ms | P1 |
| F-10 | 游戏分类筛选 | 支持按类型（AAA/Indie/FPS/RPG 等）和平台标签筛选 | P2 |
| F-11 | 最低配置比对 | 将用户硬件与游戏最低配置逐项比对，输出每项"达标/不达标/未知" | P0 |
| F-12 | 推荐配置比对 | 将用户硬件与游戏推荐配置逐项比对，输出每项"达标/不达标/未知" | P0 |
| F-13 | 综合判定 | 根据比对结果输出四档结论：`excellent` / `good` / `low` / `failed` | P0 |
| F-14 | 判定可视化 | UI 上用颜色区分（绿=可运行、黄=勉强、红=不可运行），并附文字说明 | P0 |
| F-15 | 批量检测 | 支持一次性选择多款游戏进行兼容性检查，结果以列表展示 | P1 |

### 1.3 优化建议

| # | 验收项 | 通过条件 | 优先级 |
|---|--------|---------|--------|
| F-16 | 针对性建议 | 对每项不达标的硬件，给出至少 1 条具体建议（如"将内存从 8GB 升级至 16GB"） | P0 |
| F-17 | 建议分级 | 建议按优先级排序（高/中/低），用户一眼看到最重要的改进项 | P1 |
| F-18 | 建议可执行性 | 软件类建议（如关闭后台程序、更新驱动）标注为"可自动执行"或给出操作步骤 | P2 |

### 1.4 数据管理

| # | 验收项 | 通过条件 | 优先级 |
|---|--------|---------|--------|
| F-19 | 历史记录 | 保存最近 10 次检测记录，可查看详情、可删除单条或全部 | P1 |
| F-20 | 自定义游戏 | 支持用户手动添加游戏及其配置要求（名称、CPU/GPU/内存/磁盘要求） | P1 |
| F-21 | 游戏数据导入/导出 | 支持 JSON 格式导入和导出游戏数据库 | P2 |
| F-22 | 报告导出 | 将检测结果 + 兼容性评估 + 优化建议导出为 PDF 文件，格式清晰可读 | P1 |

## 二、性能验收

| # | 验收项 | 通过条件 | 测试方法 |
|---|--------|---------|---------|
| P-01 | 冷启动时间 | 从双击图标到主界面可交互 ≤ 3 秒 | 秒表计时 × 5 次取平均 |
| P-02 | 热启动时间 | 关闭后重新打开 ≤ 1 秒 | 秒表计时 × 5 次取平均 |
| P-03 | 硬件检测耗时 | 全量检测（CPU+GPU+内存+磁盘+OS）≤ 5 秒 | 代码内计时 `scanTimeMs` |
| P-04 | 单款游戏评估耗时 | 兼容性计算 + 建议生成 < 100ms | 代码内计时 |
| P-05 | 批量检测耗时 | 50 款游戏连续评估 < 3 秒 | 代码内计时 |
| P-06 | UI 响应延迟 | 用户点击按钮后 ≤ 100ms 给出视觉反馈（进度/跳转/弹窗） | 人工感知 + DevTools |
| P-07 | 空闲内存占用 | 主界面静止状态 ≤ 100MB | 任务管理器 / Activity Monitor |
| P-08 | 检测峰值内存 | 检测过程中 ≤ 200MB | 任务管理器 / Activity Monitor |
| P-09 | 空闲 CPU 占用 | 主界面静止 ≤ 3% | 任务管理器 / top |
| P-10 | 检测峰值 CPU | 检测过程中瞬时 ≤ 30%，持续时间不超过 5 秒 | 任务管理器 / top |
| P-11 | 安装包体积 | Windows ≤ 50MB、macOS ≤ 60MB、Linux ≤ 40MB | 打包后检查文件大小 |
| P-12 | 游戏列表渲染 | 100 款游戏滚动无卡顿（≥ 60fps） | DevTools Performance 面板 |

## 三、跨平台验收

### 3.1 Windows

| # | 验收项 | 通过条件 |
|---|--------|---------|
| C-01 | 支持版本 | Windows 10 1909+ 及 Windows 11，功能完整无崩溃 |

### 3.2 macOS

| # | 验收项 | 通过条件 |
|---|--------|---------|
| C-07 | 支持版本 | macOS 12 Monterey 及以上，Intel 和 Apple Silicon 双架构 |
| C-08 | 安装体验 | 双击 .dmg 拖入 Applications 即可使用 |
| C-09 | 代码签名 | 应用经过 Apple Developer ID 签名，Gatekeeper 不弹"未知开发者"警告 |

| C-12 | 沙盒兼容 | 应用在无网络权限的情况下核心功能正常 |

### 3.3 Linux

|---|--------|---------|

## 五、安全与隐私验收

| # | 验收项 | 通过条件 | 优先级 |
|---|--------|---------|--------|
| S-01 | 离线运行 | 断网状态下所有功能正常（检测、评估、导出） | P0 |
| S-02 | 无数据上传 | 网络监控工具确认运行期间无外发请求（除非用户主动触发更新检查） | P0 |
| S-03 | 无遥测 | 不包含任何埋点、追踪、匿名统计代码 | P0 |
| S-04 | 本地数据存储 | 数据库文件存储在系统标准目录（AppData/Application Support/.config），权限仅当前用户可读写 | P0 |
| S-05 | 无广告 | 界面不含任何第三方广告、推广链接、赞助商内容 | P0 |
| S-06 | 权限最小化 | 不请求不必要的系统权限；如需读取敏感硬件信息，弹窗说明用途并征得同意 | P0 |
| S-07 | 代码签名 | 三个平台安装包均经过有效数字签名，校验通过 | P0 |
| S-08 | 依赖审计 | 所有第三方 crate/npm 包无已知高危漏洞（`cargo audit` + `npm audit` 通过） | P1 |
| S-09 | 安装包完整性 | 提供 SHA-256 校验值，用户可验证下载文件未被篡改 | P2 |

## 七、发布验收清单（v1.0 发布前必须全部 ✅）

### 功能完整性
- [ ] 所有 P0 功能验收项通过
- [ ] 至少 80% 的 P1 功能验收项通过
- [ ] 游戏数据库包含 ≥ 100 款游戏

### 质量门槛
- [ ] 所有 P0 性能验收项达标
- [ ] 三个目标平台均通过安装 + 核心功能测试
- [ ] 单元测试覆盖率达标（Rust ≥ 85%, TS ≥ 75%）
- [ ] `cargo clippy` 零警告、`npm run lint` 零错误
- [ ] 无 P0/P1 级别已知 Bug

### 安全合规
- [ ] 离线运行验证通过
- [ ] 网络监控确认无数据外泄
- [ ] 安装包代码签名有效
- [ ] 依赖漏洞扫描无高危项

### 交付物
- [ ] 三个平台安装包（Windows .msi / macOS .dmg / Linux .deb + .AppImage）
- [ ] 每个安装包附带 SHA-256 校验文件
- [ ] 用户使用手册（PDF/HTML）
- [ ] CHANGELOG.md 更新至 v1.0
- [ ] GitHub Release 页面完整（版本说明 + 下载链接 + 校验值）

## 优先级说明

| 优先级 | 含义 |
|--------|------|
| **P0** | 必须实现，不通过则不能发布 |
| **P1** | 强烈建议实现，缺失需书面说明原因 |
| **P2** | 重要但可延后至 v1.1 |
| **P3** | 锦上添花，后续版本迭代 |
